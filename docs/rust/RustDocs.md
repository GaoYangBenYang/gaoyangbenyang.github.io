## 数据类型

### 标量类型

> 标量类型代表一个单独的值，整型、浮点型、布尔类型和字符类型。

1. 整型，默认是 `i32`
   > 整型是没有小数部分的数字，可以是正数、负数或零。

   | 长度   | 有符号   | 有符号区间                                                                              | 无符号   | 无符号区间                                       |
         |------|-------|------------------------------------------------------------------------------------|-------|---------------------------------------------|
   | 8    | i8    | -128 ~ 127                                                                         | u8    | 0 ~ 255                                     |
   | 16   | i16   | -32768 ~ 32767                                                                     | u16   | 0 ~ 65535                                   |
   | 32   | i32   | -2147483648 ~ 2147483647                                                           | u32   | 0 ~ 4294967295                              |
   | 64   | i64   | -9223372036854775808 ~ 9223372036854775807                                         | u64   | 0 ~ 18446744073709551615                    |
   | 128  | i128  | -170141183460469231731687303715884105728 ~ 170141183460469231731687303715884105727 | u128  | 0 ~ 340282366920938463463374607431768211455 |
   | 架构相关 | isize | 64 位架构上它们是 64 位的，32 位架构上它们是 32 位的                                                  | usize | 64 位架构上它们是 64 位的，32 位架构上它们是 32 位的           |

2. 浮点型，默认是 `f64`
   > 浮点型是带小数部分的数字，Rust 的浮点数类型是 f32 和 f64，分别占 32 位和 64 位。默认类型是 f64，因为在现代 CPU 中，它与 f32
   速度几乎一样，不过精度更高。所有的浮点型都是有符号的。

3. 布尔类型`bool`，默认是 `false`
   > 布尔类型表示真或假，只有两个可能的值：`true` 和 `false`。

4. 字符类型`char`
   > 字符类型表示一个字符，用单引号括起来，例如 `'a'`，而字符串字面值使用的是双引号。

### 复合类型

> 复合类型可以把多个值组合成一个类型，元组和数组。

1. 元组
   > 元组是一个固定长度的集合，可以包含不同类型的值。
   >
   > 元组用圆括号括起来，例如 `(1, 2.0, 'a')`。
   >
   > 元组的每个元素都有一个索引，从0开始。
   >
   > 元组的长度在编译时是已知的。

2. 数组
   > 数组是一个固定长度的集合，可以包含相同类型的值。
   >
   > 数组用方括号括起来，例如 `[1, 2, 3]`。
   >
   > 数组的每个元素都有一个索引，从0开始。
   >
   > 数组的长度在编译时是已知的。

## 变量和可变性

### 不可变变量（声明关键字 `let`）

> 在 Rust 中，变量默认是不可变的。这意味着一旦变量被赋值，它的值就不能被改变。

```rust
fn main() {
    let x = 5;
    println!("{}", x);
    // x = 6; // 这行代码会报错，因为 x 是不可变的
}
```

### 可变变量（声明关键字 `let mut`）

> 在 Rust 中，变量默认是不可变的。这意味着一旦变量被赋值，它的值就不能被改变。

```rust
fn main() {
    let mut x = 5;
    println!("{}", x);
    x = 6; // 这行代码不会报错，因为 x 是可变的
}
```

## 常量

### 声明常量（关键字 `const`）

> 在 Rust 中，常量是不可变的，这意味着一旦常量被赋值，它的值就不能被改变。

```rust
fn main() {
    const X: i32 = 5;
    println!("{}", X);
    // X = 6; // 这行代码会报错，因为 X 是不可变的
}
```

## 遮蔽

> 在 Rust 中，遮蔽（shadowing）是指在相同作用域内，后声明的变量可以覆盖先声明的变量。

```rust
fn main() {
    let x = 5;
    println!("{}", x);
    {
        let x = 6;
        println!("{}", x);
    }
}
```
